# Content disclosure

Etched Refabricated is an unofficial fork of [Etched](https://github.com/jacksonhardaway/etched) by Moonflower Studio. It is not made, endorsed or supported by Moonflower Studio. This page lists where everything in it comes from.

## Code

The code is GPL-3.0, upstream and here. The license permits this fork as long as it stays GPL-3.0 and credits the original authors. It does both.

This fork's own art is GPL-3.0 too, the same as the code.

## Art

Every texture, model, screen, the Bard villager's look and the mod icon are new for this fork. Moonflower Studio keeps its art All Rights Reserved and did not grant permission to include it, so all of it was replaced, and none of it ships any more. It does remain in this repository's older commits.

The new art was made with an AI assistant (Anthropic's Claude) from the maintainer's art direction. The maintainer reviewed each piece in game and edited several models and textures by hand.

## Sounds

The Etching Table's two sounds are new, made for this fork by a composer.

## Structures

The bard's village stalls are new for this fork. They replace the original mod's bard houses, and were made with the same AI assistant from the maintainer's direction.

## Carried over from the original

Some data and text files in `src/main/resources/` come from the original mod: translations, recipes, loot tables, advancements, tags, item model files and a few config files. None of them is art. They stay All Rights Reserved by Moonflower Studio, and [LICENSE](../LICENSE) lists each one.

## Bundled libraries

Three audio decoders are bundled, unmodified and relocated: JLayer (LGPL-2.1), JAAD (public domain) and jFLAC (LGPL-2.1).
